# 三角関数ラボ

円周上の点Pを動かし、代表角ごとの `x`・`y`・`r` の比を図と数値で確かめる教材です。

## GitHub Pagesで公開する方法

1. このフォルダ内のファイルをGitHubリポジトリへアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Source` で **GitHub Actions** を選びます。
4. `main` ブランチへ反映すると、自動で公開されます。

教材本体は `public/index.html` の1ファイルです。HTML・CSS・JavaScriptをすべて含んでいるため、このファイルだけでも利用できます。

## 主な機能

- 0°から360°までの代表17角度へスナップする点Pのドラッグ操作
- 直角三角形、辺の比、角度、座標 `x`・`y`、半径 `r` の連動表示
- 各角度の `x : y : r` を最も簡単な比で表示
- スマートフォン、タブレット、PC、キーボード操作、印刷に対応
